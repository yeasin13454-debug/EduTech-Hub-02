EduTech Hub website source files

1. Keep index.html, style.css, and script.js in the same folder.
2. Open index.html in a modern web browser to preview the website.
3. The page uses Tailwind CSS CDN, Font Awesome, Google Fonts, and external image/flag URLs, so an internet connection is needed for those resources.

Note: The original JavaScript behavior is separated from the HTML; this package does not add a backend or real authentication/database.
